# ONE SAY SCHOOL MANAGEMENT SYSTEM

**Satu Data · Satu Pembelajaran · Satu Manajemen · Satu Evaluasi**

ONE SAY adalah sistem manajemen sekolah terintegrasi untuk mendukung pengelolaan informasi, administrasi, pembelajaran, dan evaluasi sekolah dalam satu platform.

## Teknologi

- React
- Vite
- Firebase Authentication
- Cloud Firestore
- GitHub Pages

## Pengembangan Lokal

Persyaratan:
- Node.js
- npm

Instal dependensi:

```bash
npm install
```

Jalankan server pengembangan:

```bash
npm run dev
```

Buat build produksi:

```bash
npm run build
```

Periksa kualitas kode:

```bash
npm run lint
```

## Status Proyek

Tahap awal: fondasi aplikasi React + Vite dan konfigurasi repository.

Integrasi Firebase, autentikasi pengguna, struktur data, dan kontrol akses akan dikembangkan secara bertahap.

## Keamanan

Data sekolah dan data murid harus dilindungi dengan autentikasi, otorisasi berbasis peran, serta aturan keamanan database. Jangan memasukkan kata sandi, token rahasia, atau kredensial admin ke repository.
